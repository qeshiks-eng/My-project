# Safety and Scope

This repository is a defensive cybersecurity engineering lab.

## Purpose

The repository is used for supplemental practice in:

- detection engineering
- incident response automation
- infrastructure hardening
- network security
- DevSecOps and Security QA
- controlled lab-based adversary emulation

## Allowed environments

All experiments must be performed only in:

- local virtual machines
- isolated lab networks
- intentionally created training environments
- owned systems
- synthetic datasets
- sanitized sample data

## Prohibited use

This repository is not intended for:

- unauthorized access
- attacking third-party systems
- credential theft
- persistence on real systems
- evasion in production environments
- collecting or publishing real secrets
- publishing private keys
- publishing real user data
- publishing production traffic dumps

## Artifact policy

Do not commit:

- passwords
- tokens
- API keys
- private keys
- real credentials
- real intercepted traffic
- production logs
- personal data
- runtime logs
- temporary files

Use placeholders, examples, and sanitized documentation instead.

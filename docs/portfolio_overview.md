# Portfolio Overview

## Purpose

This repository is a supplemental cybersecurity engineering lab.

It is designed to demonstrate practical learning progress, safe public artifacts, and engineering-style documentation.

## Target tracks

1. SOC / Detection / Network Security
2. Security Automation
3. Incident Response Automation
4. Infrastructure Security
5. DevSecOps / AppSec / Security QA

## Current strengths

- Python automation
- log parsing
- PCAP analysis
- Linux basics
- Windows event analysis basics
- Ansible hardening practice
- Suricata rule writing basics
- network security lab scenarios
- Docker / Docker Compose basics
- RBAC and Security QA experience from development practice

## Evidence model

Each mature lab should eventually include:

- goal
- scope
- lab topology
- tools used
- commands
- verification steps
- troubleshooting notes
- safe public artifacts
- lessons learned
- next improvements

## Public portfolio rule

The repository should show engineering thinking, not raw risky artifacts.

Unsafe raw lab outputs should be replaced with:

- sanitized samples
- markdown explanations
- detection rules
- defensive runbooks
- parser scripts
- safe configuration examples
